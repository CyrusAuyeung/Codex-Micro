# Micro Windows @VERSION@

适用于同款 Codex Micro 复刻键盘，支持 Windows 10 / 11 x64。

完整解压后，双击 `Micro Windows.exe`。

**普通键盘**：连接键盘的 **Codex Micro Config** Wi-Fi，在“普通键盘”页读取配置，选择实体按键并设置快捷键，预览后写入。按提示重新读取核对，再回蓝灯普通模式，以蓝牙连接 **Codex Micro KB** 使用。键位保存在键盘中，程序退出后仍然生效。

**Codex 本机改键**：切到青灯 Codex 模式，蓝牙连接 **Codex Micro**。在 Codex 页识别实体按键或旋钮动作，选择功能并启用自定义。网页可以关闭，使用本机改键时保留托盘程序运行。

**快捷键录入**：支持单个或多个修饰键，可反复试按；全部松开后点击“使用此组合”。
