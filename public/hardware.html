普通键盘 · 使用方式

  1. 长按左下触摸点，灯变红时松开，进入 Config 模式。
  2. 电脑连接 Codex Micro Config 热点，点击“读取键盘”。
  3. 选择图中的按键，录入或选择快捷键，预览并保存。
  4. 重新进入配置热点，读取核对后，切回蓝灯普通模式，以蓝牙连接 Codex Micro KB 使用。

写入并核对后，退出程序也能使用。配置期间要保持电脑联网，需要网线或另一条网络连接。

普通模式可设置 13 颗按键和旋钮按下；旋转与摇杆方向可在 Codex 模式下配置。Fn 通常由键盘内部处理，无法直接录入。

录入支持单独修饰键和多修饰键，可反复试按后确认。Ctrl + Alt + Del 等系统保留组合需要手动选择。
