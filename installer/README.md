# Micro Windows @VERSION@

启动 Micro Windows，选择需要的配置方式。

**普通键盘**：连接 Codex Micro Config 热点，读取键盘，选择按键并设置快捷键，预览后保存，再重新读取核对。切回蓝灯普通模式，以蓝牙连接 Codex Micro KB 使用。保存后退出程序也生效。

**Codex 模式**：切到青灯模式，蓝牙连接 Codex Micro。选择并识别实体按键、旋钮或摇杆动作，设置功能后应用。

**录入组合键**：等拦截就绪后试按，可录入单个或多个修饰键。全部松开后点“使用此组合”。

关闭窗口后程序保留在托盘，双击托盘图标可重新打开，右键可退出。新版可在“关于”中下载安装包，覆盖安装会保留设置。
