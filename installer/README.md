# Micro Windows @VERSION@

启动 Micro Windows，选择需要的配置方式。

**普通模式**：选择或新建本地配置，编辑后“保存修改”。连接 Codex Micro Config 热点，点击“写入键盘”，预览并确认后重新读取核对。切回蓝灯普通模式，以蓝牙连接 Codex Micro KB 使用；写入并核对后退出程序也生效。

**Codex 模式**：切到青灯模式，蓝牙连接 Codex Micro。选择并识别实体按键、旋钮或摇杆动作，设置功能后“保存修改”。

**录入组合键**：出现“请按下组合键”后试按，可录入单个或多个修饰键。全部松开后点“使用此组合”。

两个页面共用配置管理，支持新建、切换、导入导出和备份恢复。切换页面保留选择与读取状态，有草稿时会提示处理。Codex 模式另支持滚动、长拨连发和“仅测试”高亮，测试在关闭窗口后自动结束。设备信息位于两页右上角，历史值会标注读取时间。

“关于”中可以启用登录后静默驻留托盘，默认关闭。Windows 自定义与 Codex 默认控制需要切换使用；提示设备被占用时先暂停另一控制程序。

关闭窗口后程序保留在托盘，单击托盘图标可重新打开，右键可退出。新版可在“关于”中“下载更新”，校验后点击“安装并重启”，更新会保留配置与开机启动选择。
